# QR 실시간 투표 · 의견 보드 설정 가이드 (약 5분)

## 전체 구조
- **3페이지 투표:** QR을 찍으면 `vote.html`이 열리고, 보기를 누르면 Google Apps Script(서버)에 기록됩니다. 현장 거수 클릭은 휴대폰 투표와 **합산**됩니다.
- **20페이지 의견 보드:** QR을 찍으면 `idea.html`이 열리고, 적어 낸 내용이 강의 화면에 **포스트잇**으로 붙습니다.
- 강의 화면 `index.html`은 2.5초마다 서버에서 집계와 의견을 읽어 반영합니다.

## GitHub에 올릴 파일 (4개)
| 파일 | 역할 |
|---|---|
| `index.html` | 강의 화면 (QR 표시 + 실시간 집계) |
| `vote.html` | 휴대폰 투표 화면 (3페이지 QR) |
| `idea.html` | 휴대폰 의견 입력 화면 (20페이지 QR) |
| `config.js` | 투표 서버 주소·초기화 비밀번호·보기 문구 설정 |

`Code.gs`와 이 가이드는 GitHub에 올리지 않습니다.

## 1단계. 투표 서버 만들기 (Google Apps Script)
1. Google 드라이브에서 새 **Google 스프레드시트**를 만듭니다. 이름 예: `한화오션_현장책임자_투표`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고, 제공된 `Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
   - 초기화 비밀번호를 바꾸려면 맨 위 `ADMIN_KEY` 값을 바꿔 주세요.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(톱니바퀴): **웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한 승인 화면이 나오면 본인 계정으로 허용합니다.
   - **"Google hasn't verified this app"(확인되지 않은 앱)** 화면은 본인이 만든 스크립트면 항상 나오는 정상 화면입니다.
     왼쪽 아래 **Advanced(고급)** → **Go to (프로젝트 이름) (unsafe)** → **Allow(허용)** 순서로 누르면 됩니다.
     (개발자 = 본인 계정이며, `@OnlyCurrentDoc` 설정으로 이 스프레드시트 1개에만 접근합니다.)
6. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 2단계. config.js에 주소 넣기
```js
POLL_API_URL: 'https://script.google.com/macros/s/…/exec',
POLL_ADMIN_KEY: 'hanwha-2026',   // Code.gs 의 ADMIN_KEY 와 같게
```
보기 문구를 바꾸면 `config.js`의 `OPTIONS`와 `index.html` 투표 슬라이드의 보기 문구를 같은 순서로 맞춰 주세요.

## 3단계. GitHub에 업로드
저장소 → **Add file → Upload files** → `index.html`, `vote.html`, `idea.html`, `config.js` 4개를 한 번에 올리고 Commit합니다. 1~2분 뒤 반영됩니다.

## 4단계. 리허설 (강의 전 꼭 확인)
1. 강의 PC에서 `https://datathinkinglab.github.io/hanwha-ocean-field-leaders/`를 열고 3번 투표 슬라이드로 이동합니다.
2. 상태 문구가 **"● 실시간 연동 중 · 시:분:초 갱신"**인지 확인합니다.
3. 휴대폰으로 QR을 찍어 투표하고, 몇 초 안에 막대가 올라가는지 확인합니다.
4. 20페이지로 이동해 상태가 **"● 실시간 수집 중"**인지 확인하고, 휴대폰으로 의견을 하나 남겨 포스트잇이 붙는지 봅니다.
5. **투표 설정 → 전체 집계 초기화**로 투표와 의견을 모두 비운 뒤 강의를 시작합니다.

## 20페이지 의견 보드 사용법
- **QR 크게** 버튼으로 QR을 띄우고, 청중이 각자 휴대폰으로 의견을 적습니다. 한 사람이 여러 건 적어도 됩니다.
- 포스트잇의 **❤️**를 누르면 공감 수가 올라가고, **✕**를 누르면 그 의견이 지워집니다(서버에서도 삭제).
- 네트워크가 안 되는 상황에서는 아래 입력창에 강사가 대신 적어 붙일 수 있습니다.
- 의견만 따로 비우려면 **투표 설정 → 전체 집계 초기화**를 누르면 됩니다(투표 수치도 함께 0이 됩니다).
- 적힌 내용은 스프레드시트 `아이디어` 시트에 남습니다. 강의 후 정리 자료로 쓰실 수 있습니다.

## 운영 팁
- **QR 크게** 버튼으로 QR을 화면 가득 띄우면 뒷자리에서도 인식됩니다.
- 같은 휴대폰은 한 표만 집계되고, 다시 누르면 선택이 바뀝니다.
- 강의 당일 서버 주소를 바꿔야 하면 **투표 설정**에 새 주소를 넣고 "저장 · 연결 확인"을 누르면 됩니다(그 PC 브라우저에만 저장).
- 상태가 "⚠ 투표 서버 연결 끊김"이면 교육장 네트워크에서 Google 접속이 막힌 경우일 수 있습니다. 이때는 거수 후 보기 행을 클릭하는 방식으로 진행하세요.
- 투표 기록은 스프레드시트 `투표기록` 시트에 시각·세션·선택으로 남습니다(개인정보 없음).
- Code.gs를 수정했다면 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 그대로 유지됩니다.
- `config.js`는 공개 저장소에 올라가므로 초기화 비밀번호는 누구나 볼 수 있습니다. 집계 초기화 외 다른 권한은 없습니다.
